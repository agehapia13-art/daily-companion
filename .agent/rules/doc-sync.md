# ドキュメント同期ルール（README.md / SPEC.md）

`src/`、`web/`、または `workers/` 配下のコードや仕様を変更した際は、タスク完了前に必ず `README.md` と `SPEC.md` の両方を照合・更新すること。

- 変更した機能・構成・コマンド・データ構造・API・UI挙動などが `README.md` および `SPEC.md` に正確に反映されているか確認する。
- 更新が不要な軽微なリファクタリングであっても、両ドキュメントとの乖離がないことを必ず照合してから完了とする。
